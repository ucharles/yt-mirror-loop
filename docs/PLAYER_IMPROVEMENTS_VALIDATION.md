# 재생·구간 편집 개선 구현 검증 기록

기준: [PRD v0.24](PRD_PLAYER_IMPROVEMENTS.md), 2026-11-07.

## 구현

- 상시 라벨 입력 영역 제거. 삭제 왼쪽 메모 아이콘으로 대화상자를 열고 완료·취소 후 닫음. 편집 중 아이콘 재터치 시 초안 유지.

- 화면 회전 시 실제 본문 폭으로 영상·목록 너비를 재계산. 동일 세션에서 가로→세로→가로 전환 후 너비·라벨 초안·시작 마크 보존 회귀 테스트 통과. 실제 iPad 회전 결과는 재확인 필요.
- 시작·끝 마크를 동일 너비 2열, 최소 높이 56으로 변경. 삭제 아이콘을 구간 시간 오른쪽 끝으로 이동.

- 재생바 탭·드래그, 터치 중 위치 표시와 연속 탐색, 이전 엔진 시간 이벤트 차단, 원래 재생 상태 복원.
- 플레이어 화면의 네이티브 뒤로 가기 스와이프 차단. 재생바가 자기 영역의 터치를 우선 점유하며 이탈은 뒤로 버튼으로 제공. 구간 목록의 수동 스크롤은 허용.
- 직접 탐색 시 반복 범위 밖이면 반복 OFF, A/B 지점 보존. 로컬 재생 위치 프레임 이동은 정지 상태 유지.
- 임시 시작점과 버튼 활성 상태 표시, 재터치 취소, 병합 취소 시 시작점 유지.
- 현재 구간 강조만 적용. 자동 스크롤은 사용자 변경 요청으로 제거했고 구간 재생 중에도 목록을 자유롭게 스크롤할 수 있음.
- 라벨 탭 편집·완료/취소, 포커스 이탈 시 자동 저장 금지, 화면 이탈 확인.
- 라벨 초안 관련 삭제·병합 확인. 동의 전 구간 변경·미리보기·반복 해제를 보류.
- iPad YouTube 기본 컨트롤 노출, 메뉴 반전 허용. 영상별 화질·자막 저장은 추가하지 않음.
- 자막은 기본 OFF로 초기화하고 이후 수동 ON을 허용. `cc_load_policy=0`만으로 보장되지 않아 CC 버튼과 HLS 자막 트랙을 함께 처리함. 사용자 조작 전 지연된 ON 설정도 차단하고, 직접 자막을 조작하면 그 선택을 허용함.
- TV 설정은 동일한 WKWebView를 iPad의 설정 화면으로 옮겼다가 TV로 복귀시킴. 재로딩·두 번째 플레이어를 만들지 않음.

## 주의할 구현 의존성

YouTube 자막 초기화와 TV 컨트롤 표시 전환에는 iframe 안의 DOM 접근이 필요하다.
공식 IFrame 파라미터만으로 자막 강제 OFF나 화면별 컨트롤 전환을 모두 제공하지 않아 문서 시작 스크립트를 사용한다.
YouTube의 UI 구조가 바뀌면 이 부분을 다시 검증해야 한다. 영상 픽셀에 합성된 자막은 제거하지 않는다.

영상별 설정 저장·복원 및 JSON 필드는 추가하지 않았다. TV 설정 전환은 같은 플레이어의 일시적 화면 이동이며 영상별 설정 기억과는 다르다.

- 메모·삭제 아이콘 축소(터치 영역 유지). 메모 대화상자의 기존 값 표시·완료 저장·시스템 닫기 취소 회귀 테스트 통과. 키보드·회전 실기기 확인은 별도 필요.

- 영상 전체화면: 동일 YouTube 플레이어 인스턴스·HTML 유지, 재생·반전·시작 마크 유지, 로컬 플레이어 재로드 없음, 시스템 뒤로 가기 복귀, 외부 화면 연결 시 복귀 테스트 통과. iPad 실제 전체화면 및 회전 결과는 재확인 필요.

- YouTube 목록 재생시간: 준비 완료/시간 갱신에서 전체 길이 저장, 미확인 `--:--`, 재로드 후 보존, 같은 값 반복 저장 생략, 잘못된 값 무시 및 기존 플레이어 세션 유지 테스트 통과.
