# 영상 연습 앱 사용안내

## 평소에는

홈 화면에서 **yt-mirror-loop**를 누르면 됩니다. 컴퓨터를 연결하거나 개발 프로그램을 실행할 필요는 없습니다. 유튜브 영상을 볼 때는 인터넷에 연결해주세요.

- 영상 목록에서 영상을 선택합니다.
- 영상 아래 **재생/일시정지**로 조작합니다. 재생바를 끌어 원하는 위치로 이동할 수 있습니다.
- 재생 버튼 왼쪽 **⛶**를 누르면 전체화면, **✕**를 누르면 원래 화면으로 돌아옵니다.
- **시작 마크 → 끝 마크** 순서로 반전구간을 만듭니다. 메모 아이콘으로 설명을 적을 수 있습니다.
- 유튜브 화질·자막은 영상의 YouTube 설정 메뉴에서 바꿀 수 있습니다.

## 일주일에 두 번 확인해주세요

이 앱은 무료 Apple 계정을 사용하여 **7일 안에 사용 기간을 갱신**해야 합니다. 자동 갱신을 설정해두더라도 가끔 확인해주세요.

1. iPad를 **Wi-Fi**에 연결합니다.
2. **LocalDevVPN**을 열어 연결합니다.
3. **SideStore → My Apps**를 엽니다.
4. **Refresh All** 또는 앱 옆 남은 일수를 눌러 갱신합니다. **SideStore 자체와 yt-mirror-loop 두 앱 모두** 확인합니다.
5. 남은 일수가 늘어났으면 완료입니다. 갱신은 앱의 저장된 영상·구간을 지우는 작업이 아닙니다.

버튼 이름은 SideStore 버전에 따라 조금 다를 수 있습니다. 자동 갱신은 Wi-Fi와 LocalDevVPN이 연결된 상태에서 작동을 시도합니다.

## 앱이 열리지 않을 때

위 순서로 갱신을 먼저 시도해주세요. **SideStore도 열리지 않거나 갱신이 계속 실패하면 설치 담당자에게 연락해주세요. 앱을 삭제하지 마세요.**

## 중요한 자료 보관

영상 목록의 **내보내기**로 구간·메모·영상 목록을 파일 앱에 저장할 수 있습니다. **영상 파일 자체는 포함되지 않으므로 원본 영상도 따로 보관해주세요.**

새 버전은 설치 담당자가 전달하는 IPA 파일로 업데이트합니다. 평소 갱신만으로 새 버전이 설치되지는 않습니다.
