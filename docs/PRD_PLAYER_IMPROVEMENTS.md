## 1. 목적과 범위

재생 위치 탐색, 시작 마크의 상태 확인, 현재 반전 구간 표시를 개선한다.
탐색·구간 조정 버튼을 누를 때 라벨에 원하지 않는 문자가 들어가는 문제를 해결한다.
YouTube는 사용자가 화질을 직접 선택할 수 있어야 한다. 1080p를 권장하되 더 높은 화질도 허용한다.
선택형 자막은 기본 OFF로 시작하며 사용자가 직접 ON으로 바꿀 수 있어야 한다.
화질·자막 제어의 구현 가능성은 현재 엔진에서 별도로 검증한다.

기존 구간 정의 `[start, end)`, 최소 길이 0.2초, 겹침·접촉 구간 병합,
`baseMirror XOR inAnySegment`와 기존 영상·구간 데이터의 호환성은 유지한다.
화질·자막 설정을 영상별로 저장하거나 다음 재생에 복원하는 기능은 요구하지 않는다.
이를 위한 저장 필드·마이그레이션·JSON 확장은 추가하지 않는다.
엔진 교체와 영상 다운로드는 현재 승인된 범위에 포함하지 않는다.

## 3. 상세 요구사항

### R1. 터치 중 연속 탐색

**확정: 사용자 선택 1 (2026-11-07).** 재생 중 드래그하면 잠시 멈추고,
손가락 이동 중에도 영상 위치를 계속 탐색한다. 손을 떼면 원래 재생 상태로 돌아간다.

- 재생바의 임의 위치를 터치하고 좌우로 끌 수 있다. 기존 탭 탐색도 유지한다.
- 재생바 조작을 화면 이동·뒤로 가기 스와이프로 처리하지 않는다. 플레이어 화면의 네이티브 뒤로 가기 제스처를
  차단하고 화면 이탈은 명시적인 뒤로 버튼으로 제공한다. 구간 목록은 수동 스크롤할 수 있게 유지한다.
- 손을 떼기 전부터 재생바 위치와 현재 시간 표시가 터치 위치를 따른다.
- 드래그 중에는 엔진의 늦은 시간 이벤트가 재생바를 이전 위치로 되돌리지 않는다.
- 재생 중에 시작한 드래그는 드래그 동안 일시정지하고, 마지막 위치로 탐색한 뒤 재생을 재개한다.
- 일시정지 상태에서 시작한 드래그는 완료 후에도 일시정지 상태를 유지한다.
- 엔진 탐색은 연속 요청하되 병합·빈도를 제한하여 과도한 버퍼링과 네이티브 요청 누적을 방지한다.
  UI 갱신은 탐색 응답을 기다리지 않는다. 실제 영상 프레임의 갱신은 소스·네트워크 지연을 고려한다.
- 재생바 밖으로 움직이면 0초~영상 길이로 제한한다. 길이가 알려지지 않았거나 0이면 탐색하지 않는다.
- 회전·앱 비활성화·제스처 취소·외부 화면 전환 때 드래그 상태와 일시정지 상태가 남지 않아야 한다.
  취소 시 최종 위치·재개 여부의 세부 정책은 구현 전 확정한다.
- **확정: 사용자 선택 1 (2026-11-07), 후속 선택 1로 범위 확대.** A-B 반복 활성 중 사용자가 직접
  반복 범위 밖으로 탐색하면 반복을 OFF로 전환하고 원하는 위치로 이동한다.
  A/B 지점은 보존하고 사용자가 다시 반복을 켤 수 있게 한다.
- 앱 재생바 탭·드래그, ±초 버튼, 로컬 프레임 이동, 구간 선택·시작/끝 경계 조정에 따른 미리보기,
  외장 키보드 탐색, YouTube 기본 재생바 등 모든 직접 탐색에 동일하게 적용한다.
- 드래그 대상이 `[A, B)` 밖으로 처음 나가면 해당 탐색 전에 엔진의 반복을 해제하여 A로 되돌아가는 동작과 충돌하지 않게 한다.
  같은 드래그에서 다시 범위 안으로 돌아와도 반복은 자동으로 켜지지 않는다. 범위 안에서만 드래그하면 반복을 유지한다.
- 범위 밖으로 이동한 뒤에도 드래그 전 재생/정지 상태를 복원하는 R1 규칙은 동일하다.
  드래그 외 탐색도 아래 프레임 이동 예외를 제외하면 재생/정지 상태를 임의로 바꾸지 않는다.
  구간 경계 조정 시 경계 변경 자체는 정상적으로 저장한다. 라벨 초안과 관련된 병합은 R5의 확인 전 보류 규칙을 우선한다.
- **검토 후 확정: 사용자 선택 1 (2026-11-07).** 로컬 영상의 재생 위치를 ±1프레임 이동하는 조작은
  재생 중에도 사용할 수 있으며, 일시정지한 뒤 한 프레임 이동하고 자동으로 재생을 재개하지 않는다.
  이미 일시정지 중이면 그 상태로 한 프레임 이동한다. 화면 버튼과 외장 키보드의 프레임 이동에 동일하게 적용한다.
- 프레임 이동의 일시정지 예외는 재생 위치 이동을 대상으로 한다. 구간 시작·끝 경계의 ±1프레임 조정은
  구간 경계 편집·미리보기 규칙을 따른다. 기존 `MirrorEngine.step`의 정지 동작과 혼동하지 않는다.
- 프레임 이동 대상이 A-B 반복 범위 밖이면 R1대로 반복 OFF·A/B 보존을 적용한다.
- 정상 재생으로 B에 도달한 경우에는 기존처럼 A로 반복한다. 루프 엔진의 B→A 이동이나
  플레이어 화면 전환에 따른 위치 복원은 사용자 직접 탐색으로 처리하지 않는다.
- **기존 구현과의 차이:** 현재 YouTube 엔진은 반복이 켜진 상태에서 B 이후로 탐색하면 A로 되돌릴 수 있다.
  UI만 OFF로 표시하는 것으로는 충분하지 않으며 두 엔진과 외부 화면의 실제 반복 상태를 먼저 해제해야 한다.
- **필수 기술 검증:** 앱 버튼으로 발생한 탐색은 엔진 명령 전에 반복을 해제할 수 있지만,
  YouTube 기본 재생바는 iframe 내부에서 직접 동작한다. 사용자 탐색과 정상 재생·루프 복귀를 구분하고
  A로 되돌아가기 전에 반복을 해제할 수 있는지 확인한다. 늦은 시간 이벤트만으로 이를 보장한다고 간주하지 않는다.

**수용 기준**

- YouTube·로컬 각각 재생/정지 상태에서 10초→30초→20초로 끌면, 터치 중 재생바와 시간이 해당 위치를 따른다.
- 손을 떼기 전에 실제 탐색이 발생하며, 마지막 탐색 위치가 이전 요청 결과로 덮어써지지 않는다.
- 재생바 드래그를 재생 중 시작했으면 완료 후 재생, 정지 중 시작했으면 완료 후 정지 상태다.
- 가로·세로·재생바 양 끝·외부 화면 연결에서 동일하게 동작한다.
- A=10초, B=20초에서 반복을 켜고 25초로 드래그하면 반복이 OFF가 되고 25초에 머무르거나 그 위치부터 재생한다.
  A/B는 10초/20초로 보존된다. 15초로만 드래그하면 반복은 유지하며, 25초를 거쳐 15초로 돌아온 드래그는 OFF를 유지한다.
- 같은 반복 범위에서 재생바 탭·±초·프레임 이동·구간 선택·경계 미리보기·키보드·YouTube 기본 재생바로
  범위 밖을 탐색해도 반복 OFF·A/B 보존이 동일하게 적용된다. 정상 재생으로 B에 도달하면 반복은 유지된다.
- 로컬 영상을 재생 중 ±1프레임 버튼이나 해당 키보드 단축키를 누르면 한 프레임 이동하고 일시정지 상태로 남는다.
  반복 범위 밖으로 이동한 경우 반복은 OFF이고 A/B는 보존된다. 구간 경계의 프레임 단위 조정에는 이 정지 예외를 적용하지 않는다.

### R2. 시작 마크의 대기 상태 표시

- 시작 마크를 누른 시각에 재생바에 임시 시작점 표시를 즉시 만든다.
- 시작 마크 버튼은 끝 마크 대기 상태임을 색상과 문구로 표현하고 접근성 상태로도 전달한다.
- 임시 시작점은 재생헤드, 확정 반전 구간 색 띠, A-B 루프와 구별된다.
- 끝 마크로 유효한 구간이 생성되면 임시 시작점과 버튼 대기 상태를 해제하고 확정 구간을 표시한다.
- **검토 후 확정: 사용자 선택 1 (2026-11-07).** 끝 마크로 생성하려는 구간이 라벨 초안 폐기·병합 확인을
  필요로 하면 생성 확정 전까지 시작 마크와 버튼 대기 상태를 유지한다.
  병합 확인에 동의하고 구간 저장이 확정된 뒤에만 시작 마크를 해제한다.
- 병합 확인을 취소하면 새 구간은 생성하지 않고 시작 마크를 유지한다. 끝점은 재시도용 초안으로 보관하지 않는다.
  사용자가 다시 끝 마크를 누르면 그때의 현재 재생 위치로 끝점을 새로 지정한다.
  기존 구간과 라벨 초안, 재생·반복 상태에는 R5의 확인 취소 규칙을 적용한다.
- 끝점이 시작점 이전이거나 최소 길이에 미달하면 오류를 표시하고 시작점은 유지한다.
- 임시 시작점만으로 반전을 적용하거나 저장·내보내기 하지 않는다.
- 다른 영상으로 이동할 때 임시 시작점이 다음 영상에 남지 않는다.
- **확정: 사용자 선택 2 (2026-11-07).** 대기 중 시작 마크를 다시 누르면 기존 시작 마크를 취소한다.
  재생바의 임시 시작점과 버튼 활성 상태를 해제하고 기본 '시작 마크' 상태로 돌아간다.
  현재 위치로 시작점을 갱신하거나 선택창을 띄우지 않는다. 별도 취소 버튼은 추가하지 않는다.
- 취소는 확정된 구간·현재 재생 위치·재생/정지 상태에 영향을 주지 않는다.
  취소 후 다시 누르면 그때의 현재 위치에 새 시작 마크를 만든다.
- **기존 구현과의 차이:** 현재 `onMarkStart`는 누를 때마다 현재 위치로 시작점을 갱신한다.
  확정 요구사항 구현 시 '대기 없음 → 생성 / 대기 중 → 취소' 전환으로 변경해야 한다.

**수용 기준:** 10초에서 시작 마크를 누르면 즉시 재생바 10초 지점과 버튼 상태로 확인할 수 있다.
20초에서 끝 마크를 누르면 `[10, 20)` 구간이 저장되고 대기 표시가 사라진다.
별도 시나리오로, 10초에서 시작 마크 후 15초에서 다시 누르면 임시 시작점과 활성 상태가 사라지고
구간이 생성되지 않는다. 이후 끝 마크를 누르면 먼저 시작 지점을 지정하라는 안내를 표시한다.
시작을 10초에 지정하고 끝을 20초에 찍었을 때 병합 확인이 발생하면, 확인 중에도 10초 시작 마크가 유지된다.
확인을 취소하고 18초에서 끝 마크를 다시 누르면 새 요청의 범위는 `[10, 18)`이며, 이전 20초 끝점은 재사용하지 않는다.
확인에 동의하여 구간 저장이 확정되면 시작 마크와 버튼 대기 상태가 해제된다.

### R3. YouTube 자막·화질

**사용자 원요구:** 자막을 제외하고, 제공 화질 중 최고화질을 사용하되 최대 1080p로 제한한다.

**확정 변경 (2026-11-07):** 자동 화질만 허용하면 보기 불편할 정도의 저화질이 발생한다는
사용자 피드백에 따라, **사용자가 화질을 직접 선택할 수 있어야 한다.** 자동 화질만 제공하는 안은 채택하지 않는다.
후속 선택 1에 따라 **1080p는 권장값이며 더 높은 화질의 선택·재생도 허용한다.** 엄격한 1080p 상한은 두지 않는다.
자막 역시 후속 선택 1에 따라 **기본 OFF, 필요하면 사용자가 직접 ON 가능**으로 확정한다.
설정 UI는 후속 선택 2에 따라 **iPad에서 YouTube 기본 컨트롤을 상시 제공**하는 방식으로 확정한다.
별도 설정 모드나 앱 자체 화질·자막 설정창을 기본안으로 채택하지 않는다.

- **검토 후 확정: 사용자 선택 1 (2026-11-07).** 기본 컨트롤은 iPad 재생 화면에서만 제공한다.
  TV에는 기존 PRD §3.12대로 반전 로직이 적용된 영상만 표시하며 YouTube 기본 컨트롤·설정 메뉴를 표시하지 않는다.
- iPad 영상 위의 YouTube 기본 컨트롤에서 화질·자막 설정에 접근한다. 별도 설정 모드 진입을 필수로 요구하지 않는다.
- '상시 표시'는 앱이 기본 컨트롤을 숨기지 않는다는 뜻이다. YouTube 자체의 자동 숨김까지 막아
  매 프레임 컨트롤이 보이도록 강제하는 요구로는 해석하지 않는다. 터치로 다시 표시하여 조작할 수 있어야 한다.
- 설정 조작을 위해 앱이 별도로 일시정지하거나 반전을 해제하지 않는다. YouTube 메뉴 자체 동작은 실기기에서 확인한다.
- **검토 후 확정 (2026-11-07).** YouTube 기본 컨트롤·메뉴는 영상과 함께 좌우 반전되어도 된다.
  메뉴 글자·배치를 별도로 정상 방향으로 되돌리는 기능은 요구하지 않는다. 전체 iframe 반전 방식은 이 요구와 충돌하지 않는다.
  반전된 상태에서도 화면에 보이는 항목을 터치하여 의도한 메뉴·설정을 조작할 수 있어야 한다.
- 앱의 기존 재생바·미세 탐색·속도 조절도 유지한다. YouTube 기본 컨트롤로 변경한 재생 위치·재생 상태·속도가
  앱 UI와 어긋나지 않아야 한다. 기본 재생바로 A-B 범위 밖을 탐색할 때도 R1의 반복 OFF·A/B 보존 정책을 적용한다.

- 앱 안에서 화질 선택 경로를 제공하고, 사용 가능한 해상도 중 사용자가 직접 선택할 수 있어야 한다.
  자동 모드를 선택 사항으로 제공할 수는 있지만 자동 모드만 제공해서는 완료 조건을 충족하지 못한다.
- 선택 UI가 뜨는 것만이 아니라 실제 영상 화질에 선택이 적용되는지 iPad에서 검증한다.
  영상 원본·기기·HLS 경로가 해당 화질을 제공하지 않으면 제공되는 것처럼 표시하지 않는다.
- 선택 시점의 재생 위치와 재생/정지 상태, 속도, 반전 구간, A-B 루프를 보존한다.
  재생 시작·탐색·반전 전환 때마다 임의로 자동 모드로 초기화되지 않는지 검증한다.
- 1080p는 권장 화질로 안내하며 강제 적용·상한 제한하지 않는다. 실제 제공되는 더 높은 화질도 선택할 수 있다.
- **최종 확정 (2026-11-07):** 영상별 설정을 기억할 필요는 없다는 사용자 지시에 따라,
  이전의 영상별 화질 저장·앱 재시작 후 복원 요구는 철회한다. 핵심은 **화질을 직접 선택할 수 있고 자막은 기본 OFF**인 것이다.
- 화질·자막을 위한 영상별 저장 필드, 설정 복원, 저장 데이터 마이그레이션, JSON 내보내기 옵션을 추가하지 않는다.
  선택한 화질을 앱이 읽어 영구 저장하거나 다음 재생에 강제 재적용하는 기능은 수용 기준에서 제외한다.
  영상을 다시 열 때 화질은 필요하면 사용자가 다시 선택한다. 자막은 기본 OFF를 적용한다.

- 자막 범위는 YouTube의 선택형 자막(CC·자동 생성 자막)이다. 영상 픽셀에 합성된 자막의 제거는 제외한다.
- 영상을 열면 선택형 자막은 OFF로 시작한다. 사용자가 ON으로 바꾸면 같은 재생 세션에서는 그 선택을 유지한다.
  이후 ON/OFF를 직접 전환할 수 있어야 한다. 사용자가 자막을 명시적으로 조작하기 전까지는 YouTube가 지연 적용한 ON 설정도 OFF로 유지한다.
  사용자가 직접 ON을 선택한 뒤에는 시간 갱신·탐색·반전 전환 때문에 강제로 OFF로 되돌리지 않는다.
- 외부 화면 전환 시 자막 선택을 보존할 수 있는지 검증한다. 다른 영상 열기·앱 재시작 후 재열기는 기본 OFF를 적용한다.
- IFrame 공식 API 문서에는 화질을 강제 선택하는 지원 메서드가 없다.
  `onPlaybackQualityChange`로 화질 변경을 관찰할 수 있다는 사실이 1080p 고정이나 상한 보장을 의미하지 않는다.
- `cc_load_policy=1`은 기본 자막 표시를 강제하지만, 그 외 기본 동작은 사용자 설정을 따른다.
  `cc_load_policy=0`만으로 모든 환경에서 자막 OFF를 보장한다고 정의하지 않는다.
- 현재 iPad·TV YouTube 플레이어는 동일한 HTML을 사용하지만 서로 다른 WebView에서 실행된다.
  자막과 화질은 두 경로 모두 실제 기기 검증이 필요하다.
- **확정: 사용자 선택 1 (2026-11-07).** TV 연결 중 화질·자막을 변경하려면 재생을 iPad로 잠시 옮겨
  YouTube 기본 컨트롤에서 설정하고, 설정을 마친 뒤 TV 재생으로 복귀하는 경로를 제공한다.
  TV 재생을 유지한 채 별도 앱 설정창으로 원격 제어하는 방식을 요구하지 않는다.
- 임시 전환과 복귀 시 재생 위치·재생/정지 상태·속도·반전 설정·구간·A-B 설정을 보존한다.
  iPad와 TV의 플레이어 두 개가 동시에 재생되지 않아야 한다. 복귀 후 화질·자막도 사용자가 선택한 값을 유지해야 한다.
- **필수 기술 검증:** 현재 화면 전환은 WebView를 교체하므로, iPad 기본 메뉴에서 선택한 화질·자막을
  TV WebView에 전달·재적용할 수 있는지 확인해야 한다. 같은 HTML이나 사용자 환경을 사용한다는 이유만으로
  선택값이 유지된다고 간주하지 않는다. 전달할 수 없다면 이 요구는 미충족으로 보고하고 재논의한다.
- iPad 임시 전환은 화질·자막 설정을 위한 화면 이동이며 앞서 제외한 '설정 시 반전 해제 모드'와 다르다.
  기본 메뉴는 반전된 상태를 허용하며, 설정을 위해 별도로 반전을 해제하지 않는다.
- 현재 엔진은 재생 안정성을 위해 MediaSource를 숨겨 네이티브 HLS 경로를 사용한다.
  화질 제어 목적으로 이 경로를 바꾸는 경우 기존 재생·버퍼링·반전·TV 연결 검증이 다시 필요하다.
- **미결·구현 전 기술 검증:** 수동 화질 선택과 자막 기본 OFF·수동 ON 요구는 확정했지만 제공 방법은 미확정이다.
  현재 구성에서 수동 선택이 불가능하면 제한 사항을 보고하고 엔진 변경 여부를 별도 결정한다.
  지원되지 않는 API를 호출하거나 화면에 선택값만 표시한 것을 완료로 처리하지 않는다.

**현재 구현과의 구체적 충돌**

- **설정 메뉴 숨김:** 현재 `controls=0`이므로 YouTube 기본 화질 메뉴에 접근할 수 없다.
  확정한 화면별 요구에 맞게 iPad는 기본 컨트롤을 제공하고 TV는 숨기도록 구분해야 한다.
  iPad의 `controls=1` 경로를 검증하되,
  이것만으로 iPad HLS에서 해상도 선택 메뉴가 제공된다고 단정하지 않는다.
- **메뉴 반전은 허용된 동작:** 현재 iframe 전체를 감싸는 `#mirror`에 `scaleX(-1)`을 적용한다.
  기본 설정 UI의 메뉴·글자도 반전되는 동작을 사용자가 허용했다. 메뉴를 정상 방향으로 분리하기 위한 기술 검증은 필요하지 않다.
  기본 컨트롤 노출 후 반전된 항목의 터치 조작은 구현 후 확인한다.
- **TV는 직접 조작 불가:** 외부 화면 모드에서는 iPad의 YouTube WebView를 없애고 TV의 WKWebView 하나만 재생한다.
  TV에 메뉴를 표시하는 것만으로는 iPad에서 화질을 선택할 수 없다. 검토 후 TV에는 기본 컨트롤을 숨기기로 확정했으므로
  기존 'TV에는 영상만' 요구는 유지하며, 설정은 앞서 확정한 iPad 임시 전환 경로로 제공한다.
  별도 플레이어 두 개를 동시에 실행하는 방식은 기존 단일 플레이어 설계와 충돌하므로 임의로 채택하지 않는다.
  확정한 iPad 임시 전환을 위해 외부 디스플레이 연결 상태와 실제 재생 대상 화면을 별도로 다루는 설계가 필요하다.
  현재는 `external.connected`에 따라 바로 TV 모드로 전환되므로 물리 연결 유지 중 iPad 재생을 지원하는지 검증한다.
- **앱 자체 선택기:** 현재 공식 API만으로는 앱의 360p/720p/1080p 버튼을 실제 플레이어에 연결하는 제어 경로가 없다.
  기본 YouTube 메뉴 방식과 별도 기술 검증이 필요한 앱 자체 선택기를 구분한다.
- **영상별 설정 저장은 검증 대상에서 제외:** 영상별 화질·자막 기억 요구를 철회했으므로,
  다음 재생을 위한 선택값 수집·저장·복원 가능성은 검증하지 않는다.
  다만 같은 재생 세션에서 iPad 설정 후 TV로 복귀할 때 선택이 적용되는지는 앞서 확정한 TV 조작 경로의 검증 대상으로 남는다.

**수용 기준 초안**

- 원본이 1080p를 지원하는 테스트 영상에서, 실기기에서 제공되는 화질 목록을 열고 직접 선택하여 실제 재생에 반영할 수 있다.
- 선택 전후에 현재 위치·재생 상태·속도·반전 구간·루프가 유지된다.
- 반전 ON/OFF 모두 화면에 보이는 메뉴 항목을 터치하여 설정할 수 있고 앱 탐색 UI와 충돌하지 않는다.
  반전 ON에서 메뉴의 글자·배치가 좌우 반전되는 것은 허용하며, 이를 정상 방향으로 되돌리지 않아도 수용 기준을 충족한다.
- iPad에서 별도 설정 모드 없이 영상 위의 YouTube 기본 컨트롤에서 화질·자막 설정을 열 수 있다.
  YouTube가 컨트롤을 자동으로 숨긴 경우 영상을 터치하면 다시 조작할 수 있다.
- TV에는 YouTube 기본 컨트롤·설정 메뉴가 표시되지 않는다. TV 설정 요청 시 iPad 임시 전환 경로를 사용하고,
  TV 복귀 후에는 기본 컨트롤을 다시 숨긴다.
- YouTube 기본 컨트롤에서 탐색·재생/정지·속도 변경 후 앱 표시가 실제 엔진 상태와 일치한다.
- 저해상도 원본·선택 불가 환경에서 지원하지 않는 화질이 적용됐다고 표시하지 않는다.
- 1080p 초과 화질이 제공되는 환경에서는 해당 화질 선택을 앱 정책으로 차단하지 않는다.
- 자막 기본 설정이 ON인 환경에서도 영상을 열면 OFF이며, 수동 ON 후 탐색·반전 전환을 해도 선택이 유지된다.
- 자막이 없는 영상은 자막 ON이 적용된 것처럼 표시하지 않는다. 영상에 합성된 글자는 제거 대상이 아니다.
- TV 연결 중 설정을 요청하면 iPad에서 기본 화질·자막 메뉴를 조작할 수 있고 설정 후 TV로 복귀할 수 있다.
  전환 과정에 동시 재생이 없으며 복귀 후 위치·재생 상태·속도·반전·구간·루프와 선택한 화질·자막이 보존된다.
- 영상 재열기·앱 재시작 후 이전 화질·자막 설정의 복원은 완료 조건으로 요구하지 않는다.
  다시 열린 영상에서도 화질을 직접 선택할 수 있고, 자막은 기본 OFF여야 한다.
- 화질·자막 설정을 위한 저장 필드·JSON 필드를 추가하지 않는다. 기존 구간·영상 데이터의 저장과 내보내기는 유지한다.

### R4. 현재 반전 구간 강조와 자유로운 목록 스크롤

- **최종 변경:** 사용자 지시에 따라 자동 스크롤은 제외한다. 앞선 자동 추적·편집 중 추적 유지 결정은 철회한다.
- 현재 재생 위치가 `start <= t < end`인 구간을 강조하고 구간 밖이면 강조를 해제한다.
- 전체 반전 ON에서 해당 구간의 영상이 원본으로 보이더라도 목록의 현재 구간 강조는 유지한다.
- 구간 생성·수정·병합·탐색 후에는 최종 저장 목록과 현재 시간으로 강조를 다시 계산한다.
  끝 마크 직후 `t == end`이면 새 구간이 강조되지 않는 것은 기존 `[start, end)` 정의와 일치한다.
- 재생·일시정지·구간 진입·재생바 조작 중에도 목록의 수동 스크롤을 막지 않는다.
  현재 구간이 화면 밖에 있어도 목록을 강제로 이동시키거나 사용자가 선택한 스크롤 위치로 되돌리지 않는다.
- 일시정지 중 탐색과 재생바 드래그 중에도 현재 위치의 구간 강조만 갱신한다.
  드래그 중에는 R1의 임시 탐색 위치를 사용하여 늦은 엔진 시간 때문에 강조가 이전 구간으로 돌아가지 않게 한다.
- 수동 스크롤은 재생 위치·재생 상태·반전·루프·라벨 초안을 변경하지 않는다.

**수용 기준:** 반전 구간 재생 중 목록을 위아래로 자유롭게 스크롤할 수 있다.
다음 구간으로 진입하거나 다른 구간으로 탐색해도 목록은 자동 이동하지 않으며 현재 구간의 강조만 바뀐다.
일시정지와 라벨 편집 중에도 같은 규칙을 적용하고, 입력 내용이 다른 구간에 저장되거나 사라지지 않는다.

### R5. 탐색·구간 조정과 라벨 입력의 분리

- **확정: 사용자 선택 1 (2026-11-07).** 라벨은 평소 입력란 대신 텍스트로 표시하고,
  사용자가 라벨을 누르면 해당 구간의 라벨 편집 모드로 전환한다. 빈 라벨에도 편집 진입점을 표시한다.
  항상 입력란을 노출하거나 별도 팝업에서 편집하는 방식을 기본안으로 채택하지 않는다.
- 라벨을 누르는 동작은 편집 진입에만 사용하고 구간 시작점으로 탐색하지 않는다.
  기존 구간 시간 범위를 누르는 동작은 해당 시작점으로 탐색하는 기능을 유지한다.
- **확정: 사용자 선택 1 (2026-11-07).** 라벨 편집에는 '완료'와 '취소'를 제공한다.
  완료를 누르면 초안을 해당 구간의 라벨로 저장하고 편집을 종료한다. 취소를 누르면 초안을 버리고
  편집 전 라벨로 돌아간다. 빈 값으로 완료하면 기존 규칙대로 라벨을 제거한다.
- 편집 중 다른 재생·탐색·구간 조정 버튼을 눌러도 라벨 초안을 자동 저장하거나 버리지 않는다.
  해당 버튼의 동작은 실행하며 초안은 유지한다. 입력란이 포커스를 잃는 것만으로 저장하지 않는다.
  사용자가 목록을 스크롤해도 같은 규칙을 적용한다.
  단, 아래 라벨 초안 폐기 확인이 필요한 삭제·병합 요청은 확인 전 조작 보류 규칙을 우선 적용한다.
- 완료 전 초안은 영상의 저장 데이터·내보내기 JSON에 반영하지 않는다. 완료 후에는 기존 즉시 저장 규칙을 따른다.
  이는 기존 PRD §3.10의 '별도 저장 버튼 없음'을 라벨 편집에 한해 보완한다.
  '완료'는 라벨 초안 확정이며 별도의 영상 전체 저장 단계를 추가하지 않는다.
- **확정: 사용자 선택 1 (2026-11-07).** 저장하지 않은 라벨 변경이 있는 상태에서 플레이어 화면을 나가거나
  다른 영상으로 이동하려고 하면 '저장하고 이동 / 버리고 이동 / 계속 편집' 확인창을 표시한다.
  저장하고 이동은 해당 라벨을 확정·저장한 뒤 원래 요청한 이동을 수행한다.
  버리고 이동은 초안만 폐기하고 기존 저장값을 유지한 채 이동한다.
  계속 편집은 이동을 취소하고 초안을 유지한다. 변경 없는 편집 상태는 확인 없이 이동할 수 있다.
- 위 확인은 앱 안에서 요청한 화면 이동에 적용한다. 앱 강제 종료 시 확인창이나 초안 복원을 보장하지 않는다.
- **확정: 사용자 선택 2 (2026-11-07).** 저장하지 않은 라벨 변경이 있는 구간을 삭제하거나
  다른 구간과 병합하려 하면 초안을 버리고 진행할지 확인한다.
  동의하면 초안만 폐기하고 편집을 종료한 뒤 요청한 삭제·병합을 기존 규칙대로 적용한다.
  미완료 라벨을 자동 저장하거나 병합 후 구간에 초안으로 이관하지 않는다.
- 확인을 취소하면 삭제·병합과 그 원인이 되는 구간 변경을 적용하지 않고 기존 구간과 라벨 초안을 유지한다.
  병합을 유발하는 경계 조정·새 구간 생성 등은 실제 저장·엔진 반영 전에 충돌을 확인해야 한다.
  먼저 병합하여 구간 ID를 없앤 뒤 초안 폐기 여부를 묻는 방식은 허용하지 않는다.
- **검토 후 확정: 사용자 선택 1 (2026-11-07).** 병합 확인에 동의하기 전에는 구간 변경뿐 아니라
  해당 요청에 따른 미리보기 탐색과 반복 해제도 모두 보류한다. 동의하면 보류한 요청을 한 번만 실행하며,
  탐색 대상이 반복 범위 밖이면 R1대로 실제 탐색 전에 반복을 OFF로 전환하고 A/B를 보존한다.
- 확인을 취소하면 보류한 요청을 폐기한다. 해당 요청으로 재생 위치·재생/정지 상태·반복 설정을 변경하지 않는다.
  확인 중에도 정상 재생은 진행될 수 있으므로, 취소 시 확인창을 열었던 과거 시각으로 강제 복원하지 않는다.
  이 규칙은 '다른 버튼은 실행하며 초안 유지' 및 '경계 조정은 즉시 저장·미리보기'의 예외로 우선 적용한다.
- 병합에 동의한 경우 확정 저장된 라벨은 기존 `normalize`의 라벨 보존 규칙을 따른다.
  초안이 없는 구간까지 라벨 초안 확인을 요구하지 않는다. 기존 삭제 확인이 별도로 필요하면 중복 확인 없이 동의 내용을 명확히 표현한다.
- 편집 모드 전환만으로 오입력 버그가 해결됐다고 판단하지 않는다.
- 공통 탐색(±5/±1/±0.1초), 구간 시작·끝 조정, 프레임 이동 버튼을 터치해도 라벨에 문자가 삽입되지 않는다.
- 라벨을 직접 편집한 경우에만 라벨 값이 바뀐다. 탐색·구간 조정만으로 라벨이 생성·수정·삭제되지 않는다.
- 라벨 편집 직후 버튼을 눌러도 입력한 내용과 구간 경계 변경이 서로 덮어써지지 않는다.
- 구간 정렬·병합 후에도 라벨과 편집 대상은 올바른 구간에 연결된다. 기존 병합 시 라벨 보존 규칙을 따른다.
- 외장 키보드가 연결된 경우 텍스트 입력 중 단축키와 일반 문자 입력이 충돌하지 않아야 한다.
  터치 버그의 원인이 키보드 단축키라고 단정하지 않는다.
- **미결:** 사용자가 말한 버튼이 재생 위치 이동인지 구간 시작·끝 조정인지, 삽입되는 문자와 포커스·키보드 상태.
  실기기 재현으로 확인한다. 현재 구간 경계 조정에는 ±5초 버튼이 없으므로 이를 추가하는 요구로 해석하지 않는다.

**수용 기준:** 빈 라벨·기존 라벨·한글 조합 중·편집 직후 각각에서 버튼을 연속 터치해도
라벨에 버튼 문자나 숫자가 입력되지 않는다. 의도한 탐색·경계 변경은 한 번씩 실행된다.
평소에는 라벨 입력란과 키보드가 활성화되지 않으며, 라벨을 직접 누른 경우에만 편집할 수 있다.
라벨 탭은 탐색을 발생시키지 않고, 시간 범위 탭은 기존처럼 구간 시작점으로 탐색한다.
기존 라벨 '뒤돌기'를 '후렴'으로 편집한 뒤 탐색 버튼을 눌러도 저장 라벨은 '뒤돌기', 초안은 '후렴'으로 유지된다.
완료하면 '후렴'을 저장하고, 취소하면 '뒤돌기'로 복귀한다. 취소 뒤 다시 편집할 때 폐기한 초안이 나타나지 않는다.
미완료 변경이 있는 상태에서 뒤로 가기·다른 영상 열기를 요청하면 확인창이 표시된다.
저장하고 이동 후 재진입하면 새 라벨, 버리고 이동 후 재진입하면 기존 라벨이 표시되며,
계속 편집을 선택하면 이동 없이 초안이 유지된다.
미완료 라벨이 있는 구간의 삭제·병합 시 초안 폐기 확인이 먼저 표시된다.
동의하면 초안을 저장하지 않고 요청을 적용하며, 취소하면 구간 경계·목록·저장 라벨·초안이 그대로 유지된다.
새 구간 생성이나 다른 구간의 경계 조정이 편집 중 구간과의 병합을 유발하는 경우에도 동일하게 확인한다.
반복 범위 밖 경계로 조정하여 병합 확인이 뜨더라도 동의 전에는 탐색이나 반복 해제를 실행하지 않는다.
취소하면 해당 조작에 의한 구간·위치·반복 상태 변경이 없고, 동의하면 반복 해제·탐색·구간 변경을 한 번씩 적용한다.

## 화면 회전 및 구간 편집 배치 추가 요구사항 (v0.24)

- 가로 → 세로 → 가로 전환 후에도 동일한 화면 폭에서는 같은 가로 레이아웃을 유지한다. 가로의 영상·목록 너비 비율은 2:1이며, 회전 중 재생 세션·라벨 초안·시작 마크는 보존한다.
- 시작 마크와 끝 마크는 동일 너비의 2열로 배치하고 버튼 최소 높이를 56으로 늘린다.
- 구간 삭제는 구간 재생시간 행의 오른쪽 끝에 쓰레기통 아이콘으로 표시한다. 접근성 이름은 ‘반전구간 삭제’이며 기존 삭제·초안 확인 동작을 유지한다.

- 라벨 영역은 평소 숨기고 삭제 아이콘 왼쪽의 메모 아이콘으로 편집을 연다. 메모 편집은 대화상자에서 입력·완료·취소를 표시하며, 기존 라벨 데이터 및 저장·이탈 확인 동작은 유지한다. 저장된 메모는 아이콘 상태로 구분한다.

- 메모·삭제 아이콘은 약 16–20 크기로 줄이고 터치 영역 44×44는 유지한다. 메모 대화상자는 가로·세로 회전과 키보드 표시를 지원하고, 취소 또는 시스템 뒤로 가기로 닫으면 저장하지 않는다.

## 영상 전체화면

- iPad 단독 재생 화면의 영상 아래 재생·일시정지 버튼 왼쪽의 전체화면 버튼으로 영상 영역을 화면 전체에 확대한다. YouTube 및 로컬 영상 모두 제공한다.
- 전체화면에서는 앱의 제목·목록·재생 조작부·상태 표시줄을 숨기고, 안전 영역 안의 닫기 버튼으로 복귀한다. 가로·세로 방향은 현재 기기 방향을 따른다.
- 플레이어를 새로 만들지 않고 같은 화면 계층에서 크기만 바꾼다. 재생 위치·재생 상태·반전·반복·시작 마크·메모 초안을 유지한다.
- Android 시스템 뒤로 가기는 전체화면부터 닫는다. 외부 화면 연결 중에는 전체화면 버튼을 제공하지 않으며, 전체화면 중 연결되면 조작 화면으로 복귀한다.

## 영상 목록 카드와 YouTube 재생시간

- 영상 카드는 동일한 너비와 높이를 사용하며 제목 영역은 2줄을 확보하고 초과분을 말줄임표로 표시한다. 태그는 한 줄로 제한하고 파일 없음 안내는 썸네일 위에 표시한다.
- YouTube 영상의 전체 길이는 플레이어에서 확인한 뒤 선택 필드 `durationMs`에 저장한다. 아직 길이를 확인하지 못한 영상은 목록에 `--:--`로 표시한다.
- 길이는 준비 완료와 시간 갱신 이벤트 모두에서 확인한다. 0·음수·비정상 값은 기존 값을 덮어쓰지 않고 동일한 길이의 반복 이벤트는 저장 작업을 발생시키지 않는다. 길이 저장은 편집 일시를 변경하지 않는다.
- 기존 데이터는 길이 필드 없이도 로드되며, 새로 확인한 길이는 앱 재시작과 내보내기·가져오기에서도 유지한다. 별도의 YouTube API 조회는 추가하지 않는다.
